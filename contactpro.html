Ingénierie

L'alliance de la Performance C et de la Structure SQL

Contrairement aux fichiers texte classiques, notre architecture utilise des structures C pour le traitement en mémoire vive et **SQLite** pour le stockage permanent. En exploitant la directive `PRIMARY KEY` et l'indexation SQL, ce système garantit une recherche quasi-instantanée même sur de larges volumes de contacts, tout en évitant les fuites mémoire grâce à une gestion rigoureuse des pointeurs.

Implémentation Technique

Contact_Manager_Core — main.c / schema.sql
main.c Logiciel C 
typedef struct {
    int id;
    char nom[50];
    char tel[20];
} Contact;

void ajouter(sqlite3 *db, Contact c) {
    char *sql = "INSERT INTO contacts (nom, tel) VALUES (?, ?);";
    sqlite3_stmt *stmt;
    
    sqlite3_prepare_v2(db, sql, -1, &stmt, 0);
    sqlite3_bind_text(stmt, 1, c.nom, -1, SQLITE_STATIC);
    sqlite3_bind_text(stmt, 2, c.tel, -1, SQLITE_STATIC);
    
    if (sqlite3_step(stmt) == SQLITE_DONE) {
        printf("Contact enregistré!\n");
    }
    sqlite3_finalize(stmt);
}
schema.sql Moteur SQL 
CREATE TABLE contacts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    tel TEXT UNIQUE NOT NULL,
    email TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Indexation pour accélérer la recherche
CREATE INDEX idx_nom ON contacts(nom);
